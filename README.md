# Лекция 4-доп: Генерация зелёного излучения (535 нм) для аддитивных технологий

Внеплановая лекция курса по лазерным аддитивным технологиям. Тема — почему медь плохо
обрабатывается инфракрасными лазерами и как получить зелёное излучение (535 нм) из
стандартного иттербиевого волоконного лазера (1070 нм) с помощью нелинейной оптики.

## Состав репозитория

| Файл | Описание |
|---|---|
| `build_lecture_4dop.py` | Python-скрипт, который из единого текста раскадровки генерирует презентацию и PDF-раскадровку |
| `Лекция_4доп_Генерация_зелёного_излучения.pptx` | Презентация PowerPoint (8 слайдов, тёмная тема 16:9) |
| `Лекция_4доп_Раскадровка_для_лектора.pdf` | Раскадровка для лектора: полный текст, тайминги, ремарки «Доска / пауза» |
| `screenshots/` | Исходные скриншоты текстовки лекции (полная текстовка с таблицами) |

## Структура лекции (8 слайдов)

1. **Титульный** — тема и рамка лекции.
2. **План лекции** — пять пунктов: от проблемы меди до экономического предложения.
3. **Почему медь — проблема для ИК-лазеров** — спектральная поглощательная способность:
   A(1070 нм) ≈ 5% против A(535 нм) = 40–60% (в 8–12 раз больше).
4. **Прямая генерация зелёного света: почему не работает** — проблема зелёного диапазона (green gap) InGaN:
   V-дефекты, квантово-размерный эффект Штарка, мощность ≤ 0,18 Вт против нужных киловатт.
5. **Нелинейная оптика: генерация второй гармоники** — разложение поляризации
   P = ε₀(χ⁽¹⁾E + χ⁽²⁾E² + χ⁽³⁾E³ + …), вывод cos²(ωt) = (1 + cos(2ωt))/2,
   PPLN с периодом Λ ≈ 6,96 мкм, условие синхронизма Δk = 2π/Λ.
6. **Моё предложение: двухпроходная схема с активной термокомпенсацией** — печь ±0,1 °C,
   подвижный клин из плавленого кварца, формула КПД с sinc²(ΔkL/2), прецедент Imeshev–Fejer (1998).
7. **Итоговые тезисы** — пять пунктов, включая экономику (на порядок дешевле готового лазера).
8. **Заключение**.

## Запуск генерации

```bash
pip install python-pptx reportlab pillow pypdf
python build_lecture_4dop.py
```

Скрипт пересоздаёт оба выходных файла (PPTX и PDF) из текста `SCRIPT` внутри себя.

## Технические особенности

- **Греческие символы** (λ, Λ, ω, Δ, χ, η, ε, π) — настоящие Unicode-символы:
  в PPTX — шрифт Cambria Math, в PDF — Times Italic; знак «∝» и стрелки «→» —
  Segoe UI Symbol (в Times Italic/Arial этих глифов нет).
- **Степени и индексы** — настоящие надстрочные/подстрочные: в PPTX отдельные run'ы
  с `baseline`, в PDF — `<sup>`/`<sub>` (например, 10⁻¹⁹ Дж, E², χ⁽²⁾, sinc²).
- **Графика** — PIL-схемы: зонная диаграмма InGaN, домены PPLN, волны ω/2ω,
  двухпроходная схема с кварцевым клином, график sinc², диаграммы поглощения меди и экономики.
- **Тайминг** — из исходной раскадровки: суммарно ~31 минута (чтение ~130 слов/мин + доска/паузы).
